## Final Project: Gradebook

The Gradebook program:

- Reads student records from CSV files.
- Assigns letter grades from A to F.
- Calculates the number of students, mean, median, highest and lowest scores.
- Handles invalid scores and missing files.
- Generates a report sorted from highest to lowest score.

### How to Run the Gradebook

From the project root directory, run:

```bash
python gradebook/gradebook.py gradebook/students.csv
```

The program displays the class statistics and generates:

`gradebook/report.txt`
